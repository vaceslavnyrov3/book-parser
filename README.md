# Парсер каталога → Excel

Собирает товары с сайта (на примере учебного books.toscrape.com) и выгружает их в аккуратную Excel-таблицу.

## Возможности
- Обход всех страниц каталога (пагинация) или заданного количества
- Название, цена, рейтинг, наличие, ссылка на товар
- Excel с оформленной шапкой, фильтрами, закреплённой строкой и кликабельными ссылками
- Лист «Сводка»: количество, средняя / мин / макс цена
- Повторные попытки при сбоях сети и пауза между запросами

## Стек
Python 3.11+, requests, BeautifulSoup4, openpyxl

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python parser.py --pages 3    # без --pages соберёт все 1000 книг
```

Пример результата: `books_example.xlsx`
